## 🔧 Troubleshooting Common Issues

*   **Game runs slowly:** Close other programs that eat RAM, such as internet browsers. Verify your graphics drivers are up to date.
*   **Game crashes on start:** Ensure you have the latest Visual C++ Redistributable installed. Some antivirus programs flag emulators. You may need to add an exception for your game folder.
*   **Controller does not respond:** Close the emulator and unplug your controller. Plug it in again and wait for Windows to detect the device before reopening the program. 
*   **Screen flickers:** Switch between Vulkan and OpenGL in the graphics settings to see if the issue persists on the other backend.
